# Пробив по ВК ID: как проверить профиль по ссылке

Числовой ID страницы ВКонтакте и короткий адрес профиля не всегда выглядят одинаково. Пользователь может менять короткое имя, поэтому при проверке конкретной страницы полезно сохранить полную ссылку и, если он виден, числовой идентификатор. Эта инструкция посвящена поиску по ВК ID и ссылке, а не общему поиску человека по имени.

## ID, короткий адрес и имя: в чём разница

Имя в профиле может повторяться у многих людей. Короткий адрес тоже меняется. Числовой ID относится к конкретной странице и помогает не перепутать её с тёзкой, но не удостоверяет личность владельца. Если у вас есть лишь имя, сначала найдите нужный профиль и проверьте дополнительные признаки, прежде чем делать выводы.

Для запроса копируйте ссылку на профиль без лишних параметров. Не подменяйте ID номером телефона или адресом другой соцсети: это разные входные данные и разные сценарии поиска.

## Как сверять результаты

Сначала сравните точный идентификатор или ссылку. Затем посмотрите дату записи, прежние имена и контекст связи, если они доступны. Старая запись может отражать состояние страницы в прошлом. Совпадение фотографии или города само по себе недостаточно для вывода, что найден тот же человек.

Контакты и связанные аккаунты могут появиться только при наличии подходящей записи. Это не означает доступа к закрытой странице ВК или к текущим приватным данным. Если ответ пустой, проверьте формат ссылки и не делайте выводов о владельце аккаунта по одному отсутствию совпадения.

Для поиска по ФИО есть [отдельная статья](https://github.com/glaz-boga-dannye/probiv-po-imeni-i-familii). Она объясняет, почему тёзок нельзя считать одним человеком. Проверяйте собственные данные или сведения с согласия человека и не публикуйте чужие результаты в открытом доступе.
